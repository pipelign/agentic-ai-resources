# ML Fundamentals

> AI Use Disclosure: Codex was used to research, organize, and draft this guide.

A reading and viewing path for understanding how machine-learning models learn and represent information. Current resources emphasize neural networks, embeddings, and language models. Broader coverage of statistics, classical ML, and model evaluation remains part of the collection's future development.

**Background:** Basic algebra and coordinates are helpful. No programming is required for this path; the linked research papers and code examples are optional.

## 1. How a neural network learns

Start with [Neural networks and learning](../../foundations/neural-networks/neural-networks-embeddings-and-language-models.md#1-neural-networks-and-learning).

The first three 3Blue1Brown chapters introduce a network's structure, gradient descent, and backpropagation. Together they explain what the adjustable numbers do and how examples guide their adjustment.

## 2. How information becomes a vector

Continue with [Vector embeddings and word2vec](../../foundations/neural-networks/neural-networks-embeddings-and-language-models.md#2-vector-embeddings-and-word2vec).

Jay Alammar's illustrated explanation connects words, their surrounding text, and learned representations. StatQuest provides an alternative walkthrough of the same core idea.

## 3. How context changes a representation

Watch the selections in [Transformers and attention](../../foundations/neural-networks/neural-networks-embeddings-and-language-models.md#3-transformers-and-attention).

These build on embeddings to explain how information moves between positions in a sequence. The illustrated companions help keep track of tokens, vectors, and model parameters.

## 4. Where BERT fits

Read and watch [BERT and contextual representations](../../foundations/neural-networks/neural-networks-embeddings-and-language-models.md#4-bert-and-contextual-representations).

This connects contextual representations to pretraining and language-understanding tasks. For the historical thread, follow [the selected milestones](../../foundations/neural-networks/neural-networks-embeddings-and-language-models.md#selected-historical-milestones) through word2vec, GloVe, ELMo, BERT, and Sentence-BERT.

## 5. How embeddings support search

Continue with [Sentence embeddings and semantic search](../../foundations/neural-networks/neural-networks-embeddings-and-language-models.md#5-sentence-embeddings-and-semantic-search).

The cosine-similarity explainer and Sentence-BERT references connect the geometry to finding related text. Use [How the ideas connect](../../foundations/neural-networks/neural-networks-embeddings-and-language-models.md#how-the-ideas-connect) as a compact reference for the different kinds of representations.

## 6. Broaden the picture

Explore [Beyond language models](../../foundations/neural-networks/neural-networks-embeddings-and-language-models.md#beyond-language-models) for explainers on image classification, recurrent networks, and diffusion.

These show other ways to structure a neural network and apply learned representations to different kinds of data.
