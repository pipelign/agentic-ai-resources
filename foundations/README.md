# Foundations

> AI Use Disclosure: Codex was used to research, organize, and draft this guide.

Concepts shared across agent applications: how models learn, generate responses, and reason; how an agent acts; which information it uses; and how it gains access to procedures and tools.

## Topics

1. [Neural networks](neural-networks/README.md) — a viewing guide to learning, embeddings, word2vec, BERT, and the history of language representations.
2. [Language models](language-models/README.md) — generation, assistant training, reasoning models, and their relationship to neural networks and agents.
3. [Agent loops and autonomy](agent-loops-and-autonomy/README.md) — models, harnesses, tools, environments, and observable results.
4. [Context and memory](context-and-memory/README.md) — selecting information and preserving useful state across a task.
5. [Tool use and integrations](tool-use-and-integrations/README.md) — skills, protocols, hooks, and delegated work.

The collection combines visual learning resources with articles that use examples from research, business workflows, and documented coding-agent implementations. Topic indexes link to the guides and supporting resources.
